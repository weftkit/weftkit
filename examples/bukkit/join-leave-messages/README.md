# join-leave-messages

The smallest useful weftkit plugin: a wired listener replaces the default join and leave
broadcasts, with the message formatting injected as a component.

Documented class by class at
[weftkit.org/examples/join-leave-messages](https://weftkit.org/examples/join-leave-messages/).

## Build

From this directory, using the repository's Gradle wrapper:

```sh
../../../gradlew build
```

The jar lands in `build/libs/join-leave-messages-1.0.0.jar`. To use this example as a template
for your own plugin, see the [examples README](../../README.md).
