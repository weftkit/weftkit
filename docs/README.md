# weftkit docs

The documentation site for weftkit, built with
[Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) and served at
[weftkit.org](https://weftkit.org). All commands below run from this `docs/` directory.

## Local preview

```sh
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
mkdocs serve
```

Then open http://127.0.0.1:8000.
